الهدف والفوائد التسويقية والتقنية

لماذا نحتاج ربط Facebook SDK في تطبيق فلاتر؟

عند إطلاق حملات إعلانية على فيسبوك وإنستغرام لزيادة تثبيتات التطبيق (App Promotion Campaigns)، يحتاج مدير الإعلانات (Meta Ads Manager) إلى اتصال مباشر مع التطبيق للتعرف على نتائج الإعلان:

1. تفعيل زر التثبيت (Install Now)

تتحول الإعلانات من مجرد زيارات روابط ويب إلى زر مباشر لتثبيت التطبيق على متجري Google Play و App Store مع احتساب التثبيت.

2. تتبع التحويلات وتكلفة التثبيت (CPI)

تحديد التكلفة الفعلية لكل عملية تثبيت قادمة من إعلان محدد (Cost Per Install)، مما يرفع كفاءة خوارزميات الذكاء الاصطناعي لـ Meta.

3. تتبع الأحداث وسلوك المستخدم

تسجيل فتح التطبيق (`fb_mobile_activate_app`)، تسجيل الحساب، استعراض المنتجات أو العقارات، لتمكين إعادة الاستهداف (Retargeting).

إعداد لوحة Meta for Developers والبيانات المطلوبة

الحصول على مفاتيح الربط وتجهيز منصتي Android و iOS

📋 البيانات التي يجب استخراجها من لوحة Meta
البيان المطلوب الوصف المثال الافتراضي أين تجده في لوحة Meta؟
Facebook App ID المعرف الرقمي الفريد للتطبيق 1003409726093633 أعلى الصفحة في developers.facebook.com
Client Token رمز العميل المشفّر (32 خانة Hex) 403196df8e10cd71601b022eaff33dd0 Settings > Advanced > Security > Client Token
App Display Name اسم التطبيق المعروض Mondera Real Estate App Settings > Basic > Display Name
⚠️
تنبيه هام جداً بخصوص Client Token:
ابتداءً من إصدارات Facebook SDK الحديثة، أصبح وجود Client Token إلزامياً! بدونه لن تصل الأحداث إلى لوحة تحكم Meta إطلاقاً وسيعمل التطبيق بدون تتبع.
📱 بيانات يجب إدخالها داخل لوحة Meta لكل نظام

🤖 منصة Android

  • Package Name: com.codebyte.mondera
  • Class Name: com.codebyte.mondera.MainActivity
  • Key Hashes: بصمة مفتاح التوقيع بصيغة Base64 (Debug و Release).

🍎 منصة iOS

  • Bundle ID: com.codebyte.mondera
  • App Store ID: المعرف الرقمي على متجر آبل (10 أرقام) مثل 6792721128.

أمر استخراج Debug Key Hash لأندرويد عبر الـ Terminal لنظام Mac/Linux:

bash 
keytool -exportcert -alias androiddebugkey -keystore ~/.android/debug.keystore | openssl sha1 -binary | openssl base64

تثبيت حزمة Flutter الرسمية

إضافة facebook_app_events إلى مشروع فلاتر

يمكنك إضافة الحزمة مباشرة عبر الـ Terminal بأمر فلاتر السريع:

terminal 
flutter pub add facebook_app_events:^0.30.5

أو بإضافتها يدوياً داخل ملف pubspec.yaml تحت قسم dependencies::

yaml pubspec.yaml 
dependencies:
  flutter:
    sdk: flutter
  facebook_app_events: ^0.30.5

إعدادات ملفات الـ Native (Android و iOS)

حقن مفاتيح الربط في طبقة النظام لتمكين الإقلاع والربط التلقائي

1. ملف القيم: android/app/src/main/res/values/strings.xml

أنشئ الملف إذا لم يكن موجوداً، وأضف القيم الخاصة بالـ App ID و الـ Client Token:

xml strings.xml 
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <!-- مفاتيح الربط مع لوحة Meta -->
    <string name="facebook_app_id">1003409726093633</string>
    <string name="fb_login_protocol_scheme">fb1003409726093633</string>
    <string name="facebook_client_token">403196df8e10cd71601b022eaff33dd0</string>
</resources>

2. ملف المانيفست: android/app/src/main/AndroidManifest.xml

تأكد من وجود إذن الإنترنت، ثم أضف وسوم الـ <meta-data> داخل وسم <application>:

xml AndroidManifest.xml 
<manifest xmlns:android="http://schemas.android.com/apk/res/android" ...>
    <!-- إذن الإنترنت -->
    <uses-permission android:name="android.permission.INTERNET"/>

    <application ...>
        
        <!-- إعدادات Facebook SDK -->
        <meta-data
            android:name="com.facebook.sdk.ApplicationId"
            android:value="@string/facebook_app_id" />
        <meta-data
            android:name="com.facebook.sdk.ClientToken"
            android:value="@string/facebook_client_token" />

    </application>
</manifest>

1. ملف الإعدادات: ios/Runner/Info.plist

داخل وسم <dict> الرئيسي، أضف المخطط والمفاتيح التالية:

xml Info.plist 
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>fb1003409726093633</string>
        </array>
    </dict>
</array>

<!-- بيانات تعريف تطبيق Facebook SDK -->
<key>FacebookAppID</key>
<string>1003409726093633</string>
<key>FacebookClientToken</key>
<string>403196df8e10cd71601b022eaff33dd0</string>
<key>FacebookDisplayName</key>
<string>Mondera Real Estate App</string>

<!-- تفعيل التتبع التلقائي وجمع المعرفات -->
<key>FacebookAutoLogAppEventsEnabled</key>
<true/>
<key>FacebookAdvertiserIDCollectionEnabled</key>
<true/>

2. تثبيت مكتبات CocoaPods بأمان (تجنب مشاكل UTF-8)

شغل هذا الأمر داخل الطرفية (Terminal) لتثبيت حزم iOS وتجنب انهيار Ruby بسبب مشاكل الترميز:

bash 
cd ios && LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 pod install && cd ..

كود خدمة الفلاتر والتهيئة عند الإقلاع

تصميم خدمة برمجية موحدة Singleton جاهزة لجميع الأحداث

📦 1. ملف الخدمة: lib/core/service/generic/facebook_events_service.dart

تغليف كافة عمليات التتبع وحماية التطبيق من الانهيار عند حدوث أي خطأ، مع دعم التتبع التلقائي والأحداث القياسية:

dart facebook_events_service.dart 
import 'package:facebook_app_events/facebook_app_events.dart';
import 'package:flutter/foundation.dart';

class FacebookEventsService {
  FacebookEventsService._();

  static final FacebookEventsService instance = FacebookEventsService._();
  static final FacebookAppEvents _facebookAppEvents = FacebookAppEvents();

  FacebookAppEvents get client => _facebookAppEvents;

  /// تهيئة الخدمة وتفعيل التتبع التلقائي وجمع معرف الإعلانات
  /// تنبيه: تم استبدال setAdvertiserTracking بـ setAdvertiserIdCollectionEnabled لتفادي أخطاء الإصدارات الحديثة
  Future<void> initialize() async {
    try {
      await _facebookAppEvents.setAutoLogAppEventsEnabled(true);
      await _facebookAppEvents.setAdvertiserIdCollectionEnabled(true);
      debugPrint('✅ [FacebookSDK] Initialized successfully. AutoLogAppEvents enabled.');
    } catch (e) {
      debugPrint('❌ FacebookEventsService init error: $e');
    }
  }

  /// تسجيل حدث مخصص عام
  Future<void> logEvent({
    required String name,
    Map<String, dynamic>? parameters,
    double? valueToSum,
  }) async {
    try {
      await _facebookAppEvents.logEvent(
        name: name,
        parameters: parameters,
        valueToSum: valueToSum,
      );
      debugPrint('📊 [FacebookSDK] Event logged: $name, params: $parameters');
    } catch (e) {
      debugPrint('❌ FacebookEventsService logEvent error: $e');
    }
  }

  /// تسجيل حدث استعراض محتوى (عقار / منتج)
  Future<void> logViewContent({
    String? id,
    String? type,
    String? currency,
    double? price,
  }) async {
    try {
      await _facebookAppEvents.logViewContent(
        id: id,
        type: type,
        currency: currency,
        price: price,
      );
    } catch (e) {
      debugPrint('❌ FacebookEventsService logViewContent error: $e');
    }
  }

  /// تسجيل حدث إتمام إنشاء حساب جديد
  Future<void> logCompletedRegistration({String? registrationMethod}) async {
    try {
      await _facebookAppEvents.logCompletedRegistration(
        registrationMethod: registrationMethod,
      );
    } catch (e) {
      debugPrint('❌ FacebookEventsService logCompletedRegistration error: $e');
    }
  }

  /// ربط معرف المستخدم (User ID) لتتبع رحلة العميل
  Future<void> setUserID(String id) async {
    try {
      await _facebookAppEvents.setUserID(id);
    } catch (e) {
      debugPrint('❌ FacebookEventsService setUserID error: $e');
    }
  }

  /// حذف معرف المستخدم عند تسجيل الخروج
  Future<void> clearUserID() async {
    try {
      await _facebookAppEvents.clearUserID();
    } catch (e) {
      debugPrint('❌ FacebookEventsService clearUserID error: $e');
    }
  }
}
🚀 2. التهيئة السلسة في lib/main.dart

استخدام unawaited(...) لضمان عدم تأخير فتح واجهة التطبيق (Splash Screen) أثناء اتصال الـ SDK بالخادم:

dart main.dart 
import 'dart:async';
import 'package:flutter/material.dart';
import 'core/service/generic/facebook_events_service.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  // تشغيل تهيئة Facebook SDK بشكل غير متزامن بدون تجميد إقلاع التطبيق
  unawaited(FacebookEventsService.instance.initialize());

  runApp(const MyApp());
}

أشهر المشاكل التقنية وحلولها الفورية

إجابات المشاكل التي تظهر للمطورين أثناء الربط والرفع للمتجر

المشكلة السبب الشائع الحل الجذري المباشر
خطأ ترميز عند pod install روبي وبيئة ماك تفتقر إلى إعدادات ترميز UTF-8 قم بتشغيل: LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 pod install
تحذير `setAdvertiserTracking is deprecated` تحديث Meta لطريقة تتبع الإعلانات في الإصدارات الحديثة استخدم setAdvertiserIdCollectionEnabled(true) بدلاً منها
الأحداث لا تظهر نهائياً في Meta الـ Client Token مفقود أو تم وضع App Secret بدلاً منه تأكد من نسخ الـ Client Token بدقة (32 حرف) من Advanced Security ووضعه في strings.xml و Info.plist
سياسات خصوصية iOS (App Tracking Transparency) طلب آبل الشفافية عند قراءة IDFA في iOS 14.5+ إذا كنت تريد تتبع دقيق للمستخدم عبر الإعلانات، أضف حزمة app_tracking_transparency وطلب الإذن بعد تشغيل التطبيق
