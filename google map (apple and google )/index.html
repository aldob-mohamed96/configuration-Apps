الدليل الهندسي الشامل لخرائط جوجل Google Maps في Flutter

المرجع الموحد لإعداد وضبط خرائط جوجل على نظامي iOS و Android، مع ضبط الصلاحيات الدقيقة، وحل مشكلة الشاشة الرمادية، وإدارة الكاميرا والعلامات، ودعم الوضع الليلي المخصص وحل تعارض التمرير في ScrollViews.

⚡ المخصص الحي لإعدادات الخريطة في مشروعك (Live Code Customizer)

أدخل مفتاح الـ API واسم الحزمة أدناه، وسيتم تحديث وتخصيص جميع ملفات الـ XML و Swift والـ Plist وأكواد Dart في كامل الصفحة لحظياً لتناسب تطبيقك مباشرة!

1

نظرة عامة والحزم المطلوبة (pubspec.yaml)

أضف الحزم الأساسية لخرائط جوجل وتحديد الموقع الجغرافي إلى ملف pubspec.yaml:

YAML (pubspec.yaml) 
dependencies:
  flutter:
    sdk: flutter

  # Google Maps & Geolocation
  google_maps_flutter: ^2.18.0
  geolocator: ^14.0.2
  geocoding: ^4.0.0
  permission_handler: ^12.0.3
2

تفعيل الـ APIs وتأمين المفاتيح في Google Cloud Console

  1. ادخل على console.cloud.google.com > اختر مشروعك.
  2. فعّل كلاً من: Maps SDK for Android و Maps SDK for iOS.
  3. في قسم Credentials > أنشئ API Key واضبط قيود الأمان:
    • لقيد أندرويد: حدد Package Name (com.example.app) مع بصمة SHA-1 لـ Debug و Release.
    • لقيد أبل: حدد iOS apps مع الـ Bundle Identifier (com.example.app).
⚠️
شرط تفعيل الفوترة (Billing): تشترط جوجل ربط حساب فوترة نشط (Billing Account) لتعمل الخريطة، مع العلم أن جوجل تمنح رصيداً شهرياً مجانياً قدره 200 دولار يغطي آلاف طلبات الخرائط مجاناً.
3

تهيئة نظام Android (AndroidManifest.xml)

افتح ملف android/app/src/main/AndroidManifest.xml وأضف مفتاح الـ API وصلاحيات الموقع:

XML (AndroidManifest.xml) 
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- أذونات الموقع الجغرافي والإنترنت -->
    <uses-permission android:name="android.permission.INTERNET"/>
    <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
    <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>

    <application ...>

        <!-- مفتاح خرائط جوجل الرسمي لأندرويد -->
        <meta-data
            android:name="com.google.android.geo.API_KEY"
            android:value="YOUR_GOOGLE_MAPS_API_KEY"/>

    </application>
</manifest>
4

تهيئة نظام iOS (Info.plist & الأذونات)

أضف مفتاح GMSApiKey ونصوص وصف أذونات الموقع داخل ios/Runner/Info.plist:

XML (ios/Runner/Info.plist) 
<dict>
    <!-- مفتاح خرائط جوجل لنظام iOS -->
    <key>GMSApiKey</key>
    <string>YOUR_GOOGLE_MAPS_API_KEY</string>

    <!-- نصوص أذونات الموقع لمتجر App Store -->
    <key>NSLocationWhenInUseUsageDescription</key>
    <string>يحتاج التطبيق للوصول لموقعك لعرض الأماكن والخدمات القريبة منك على الخريطة.</string>
    <key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
    <string>يحتاج التطبيق للوصول لموقعك لتسهيل الملاحة والوصول للخدمات القريبة منك.</string>

    <key>LSApplicationQueriesSchemes</key>
    <array>
        <string>comgooglemaps</string>
    </array>
</dict>
5

ضبط AppDelegate.swift لنظام iOS (قراءة المفتاح الديناميكية)

عدّل ملف ios/Runner/AppDelegate.swift ليقوم بقراءة مفتاح GMSApiKey مباشرة من Info.plist وتمريره لـ GMSServices:

Swift (ios/Runner/AppDelegate.swift) 
import Flutter
import GoogleMaps
import UIKit

@main
@objc class AppDelegate: FlutterAppDelegate {
  override func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
  ) -> Bool {
    // قراءة المفتاح وتمريره تلقائياً لـ GMSServices
    if let key = Bundle.main.object(forInfoDictionaryKey: "GMSApiKey") as? String,
       !key.isEmpty {
      GMSServices.provideAPIKey(key)
    }
    return super.application(application, didFinishLaunchingWithOptions: launchOptions)
  }
}
6

ويدجت الخريطة المتكامل الجاهز للإنتاج (Widget Implementation)

قالب ويدجت فلاتر احترافي كامل يدعم طلب الأذونات تلقائياً، والتحريك السلس لكاميرا المستخدم، وإضافة العلامات التفاعلية، والتبديل للأقمار الصناعية:

Dart (Usage Template) 
GoogleMapViewTemplate(
  initialPosition: LatLng(30.0444, 31.2357),
  initialZoom: 14.0,
  enableMyLocation: true,
  enableTraffic: false,
  onTap: (latLng) {
    print("تم الضغط على الإحداثيات: ${latLng.latitude}, ${latLng.longitude}");
  },
)

الملف الكامل متاح في: google map (apple and google )/google_map_view_template.dart.

7

حل مشكلة التمرير عند وضع الخريطة داخل صفحة تمرير (Nested ScrollView)

عند وضع الخريطة داخل ListView أو SingleChildScrollView، تتوقف إيماءات تحريك الخريطة بسبب التقاط الصفحة للأصابع. لحل ذلك نستخدم EagerGestureRecognizer:

Dart (Eager Gesture Fix) 
GoogleMap(
  initialCameraPosition: CameraPosition(
    target: LatLng(30.0444, 31.2357),
    zoom: 14.0,
  ),
  gestureRecognizers: <Factory<OneSequenceGestureRecognizer>>{
    Factory<OneSequenceGestureRecognizer>(
      () => EagerGestureRecognizer(),
    ),
  },
)
8

الثيم الداكن المخصص للخرائط (Custom Dark Map Style)

يمكنك تلوين الخريطة بالوضع الليلي الفاخر بمجرد تمرير نص JSON لخاصية style داخل الـ GoogleMap عندما يكون التطبيق في الوضع الداكن:

Dart & JSON 
GoogleMap(
  style: Theme.of(context).brightness == Brightness.dark
      ? darkModeMapJsonString
      : null,
  ...
)
9

استكشاف الأخطاء الشائعة وحلولها المضمونة

❌ الخريطة تظهر كشاشة رمادية فارغة مع وجود لوجو جوجل فقط

السبب: واجهة Maps SDK for Android أو Maps SDK for iOS غير مفعلة في Google Cloud Console، أو لم يتم ربط حساب الفوترة (Billing Account)، أو أن بصمة الـ SHA-1 مقيدة بشكل خاطئ.

❌ التطبيق ينهار فجأة فور فتح شاشة الخريطة في iOS (Crash on Launch)

السبب: عدم مناداة GMSServices.provideAPIKey() في ملف AppDelegate.swift، أو أن قيمة المفتاح في Info.plist فارغة.

❌ خطأ رفض متجر App Store بخصوص أذونات الموقع الجغرافي

السبب: كتابة سبب عام أو غامض في NSLocationWhenInUseUsageDescription. يجب كتابة سبب واضح وصريح يوضح القيمة المباشرة للمستخدم داخل التطبيق.
